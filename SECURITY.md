# Security Policy

## Supported Versions

Security updates are provided only for the latest major version of `@custom-auth/core` and its official adapters.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within `@custom-auth`, please do **not** open a public issue.

Instead, please send an email to **dev.codehub99@gmail.com**.

We will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress. If you do not receive a reply within 48 hours, please reach out directly to the maintainers.

Please provide the following information in your report:
- A description of the vulnerability.
- Steps to reproduce the vulnerability.
- The version(s) of `@custom-auth` affected.
- Possible mitigations or solutions (if known).

Thank you for helping keep the community safe!
